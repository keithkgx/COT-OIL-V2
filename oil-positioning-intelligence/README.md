# Developer guide — Oil Positioning Intelligence

[Public project overview](../README.md) · [Live dashboard](https://keithkgx.github.io/COT-OIL-V2/) · [Market coverage research](docs/market-coverage.md) · [ICE integration specification](docs/ice-brent-gasoil-integration.md)

This folder holds the Python data-processing pipeline, source HTML template, official historical CFTC observations, tests, and generated standalone dashboard. The parent repository contains the GitHub Actions workflow.

## Quick start

Requires Python 3.12+ and internet access for data retrieval.

### Windows PowerShell

```powershell
git clone https://github.com/keithkgx/COT-OIL-V2.git
cd COT-OIL-V2/oil-positioning-intelligence
py -3.12 -m venv .venv
.venv\Scripts\Activate.ps1
pip install -r requirements.txt
$env:PYTHONPATH = "src"
python -m pytest -q
python -m oilcot.cli status
python -m oilcot.cli build
start dashboard\index.html
```

### macOS / Linux

```bash
git clone https://github.com/keithkgx/COT-OIL-V2.git
cd COT-OIL-V2/oil-positioning-intelligence
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
PYTHONPATH=src python -m pytest -q
PYTHONPATH=src python -m oilcot.cli status
PYTHONPATH=src python -m oilcot.cli build
# Open dashboard/index.html in your browser
```

### CLI commands

| Command | Effect |
| --- | --- |
| `python -m oilcot.cli status` | Check observation counts, markets and latest stored date |
| `python -m oilcot.cli build` | Rebuild HTML from the existing CSV without a web request |
| `python -m oilcot.cli refresh` | Query both CFTC report bases for the overlapping latest 90 days and rebuild the dashboard |
| `python -m oilcot.cli backfill` | Retrieve full history for all **enabled CFTC codes** and rebuild the dashboard |

The commands assume `PYTHONPATH=src` is set. CFTC API requests do not require credentials for ordinary access, but an optional `CFTC_APP_TOKEN` environment variable is supported. Never commit an API token.

## Dashboard interaction / sizing

The interface has three tabs:

1. **Market analysis** (default): one selected product, arranged from current positioning → historical positioning → change attribution → market participation.
2. **Compare markets**: a separate, normalized cross-contract comparison.
3. **Data & methodology**: historical data download and metric definitions.

Charts are rendered **only when their tab is visible**. Plotly's container width is measured after tab activation, and a `ResizeObserver` resizes charts when the layout width changes. This avoids the common issue where hidden-tab charts render at a tiny width until the browser is zoomed.

The source-of-truth for dashboard changes is `templates/dashboard.html`. The HTML at `dashboard/index.html` is generated by `build.py` and is replaced by the update job. Do **not** edit the generated file manually.

## Automated updates and GitHub Pages

- Main-branch scheduled runs and manual `workflow_dispatch` refresh the CFTC data, calculate metrics, and regenerate the HTML.
- Source-code pushes run tests and rebuild from **committed** historical data; they do not unnecessarily query the CFTC API.
- Workflow steps commit `data/cot_history.csv` and `dashboard/index.html` only if changed.
- GitHub Pages deployment uploads **only** the dashboard folder. The repository must have Pages configured to use **GitHub Actions**.
- The `PUBLISH_PAGES=true` repository Actions variable opts in to deployment. If Pages isn't enabled or accessible, the pipeline reports a warning rather than marking successful data updates as failed.

[GitHub Actions runs](https://github.com/keithkgx/COT-OIL-V2/actions) · [GitHub Pages settings](https://github.com/keithkgx/COT-OIL-V2/settings/pages)

A successful fetch does not mean a new report has been published. Always inspect the **position date** in the generated dashboard.

## Data and calculation conventions

- Source: CFTC Disaggregated COT, using official PRE JSON datasets (`kh3c-gbw2` Combined and `72hh-3qpy` Futures Only).
- Natural key: `(source, market, basis, position_date, cohort)`; historical re-fetching corrects revised rows without duplication.
- `net = long - short`; `gross = long + short` excludes separately reported spreading.
- `net_oi_pct = 100 * net / open_interest`.
- `change_report = current net - prior observed net` (not necessarily seven days).
- `change_long = current long - prior long`; `change_short = current short - prior short`. Therefore `change_report = change_long - change_short`.
- 7-day and 28-day comparisons use calendar-aware lookbacks with tolerances for absent report dates. The comparison tab ranks changes only when at least two markets have the same selected position date and the same reference date for that metric.
- The report-on-report change in net/OI splits into `100 × (net − prior net) / prior OI` from holdings and `100 × net × (1 / OI − 1 / prior OI)` from open interest. Both terms are in percentage points. Small discrepancies in the displayed sum can arise from rounding.
- 1Y and 3Y percentiles use a causal empirical midrank over comparable weekly-equivalent observations in the trailing calendar window; they never use future readings.
- Percentiles are relative to a contract's own history, not a probability of a price move.

Historical records may reflect source revisions, and report position dates are **not** proof of what was publicly known on that date. Do not use this database naively for publication-time strategy backtests.

## Operational checks

Before merging UI changes: run `pytest`, validate dashboard JS syntax, generate the preview HTML and check chart widths in a real browser at desktop and laptop widths. For ingestion changes, reconcile historical data with the source report and verify that a second run does not duplicate records.

If a scheduled workflow fails, inspect **Update COT and Dashboard → update** separately from the optional **Publish** job. Transient CFTC outages should not be mistaken for a methodology error. If data ingestion fails, old observations stay as-is rather than showing invented new positions.

## Usage and attribution

The project is an independent research dashboard and not an official exchange/CFTC or employer application. Only public CFTC data is included; ICE Brent/Gasoil delivery and redistribution have not been enabled. Do not commit proprietary trading-desk files, internal commentary or secrets.
